# Mavericks App — GitHub Pages

A clean, responsive developer website for Mavericks App.

## Pages

- `index.html` — home / app portfolio
- `privacy.html` — general website privacy policy
- `contact.html` — contact and support
- `assets/css/style.css` — design
- `assets/js/main.js` — theme toggle and footer year

## GitHub Pages

For the repository:

`mavericksapp/mavericksapp.github.io`

enable:

- Settings → Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

The site will be available at:

`https://mavericksapp.github.io/`

## Adding an app

When an app is released, add an app card to `index.html` and create an app-specific privacy policy page if needed.

Important: update the privacy policy to match the actual data practices and third-party SDKs used by each app. Do not claim that an app collects no data unless that is true.
